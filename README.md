# BizPadi

WhatsApp AI Companion for Nigerian SMEs.

```
bizpadi/
├── backend/     FastAPI — WhatsApp webhook, AI, matching engine
└── landing/     Static landing page — open index.html in any browser
```

## Deploy backend (Render)
Set root directory to `backend` in Render settings.

## Deploy landing (Netlify)
Drag the `landing/` folder to app.netlify.com/drop
